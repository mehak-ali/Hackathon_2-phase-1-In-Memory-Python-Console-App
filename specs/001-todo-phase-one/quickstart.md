# Quickstart for Evolution of Todo - Phase I

This guide explains how to run the Phase I to-do list application.

## Prerequisites

- Python 3.11 or higher

## Running the Application

1.  Navigate to the root of the project directory.
2.  Run the main CLI script:

    ```bash
    python -m src.cli.main
    ```

## How to Use

Once the application is running, you will see a menu of options:

```
Todo List Menu:
1. Add a new task
2. View all tasks
3. Update a task
4. Mark a task as complete
5. Mark a task as incomplete
6. Delete a task
7. Exit
```

- To select an option, type the corresponding number and press Enter.
- The application will guide you through each feature. For example, if you choose to add a task, it will prompt you for a description.
